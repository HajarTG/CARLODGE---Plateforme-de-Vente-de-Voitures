#  CARLODGE - Plateforme de Vente de Voitures

CARLODGE est une plateforme web de vente de voitures d'occasion et neuves, développée avec une base de données **SQLite**. L'application permet aux utilisateurs de rechercher, filtrer et acheter des véhicules en ligne.

##  Fonctionnalités

-  **Recherche Avancée** - Filtres par année, marque, modèle, style de carrosserie, état du véhicule et prix maximum
-  **Catalogue de Voitures** - Affichage détaillé avec images, caractéristiques et prix
-  **Paiement en Ligne** - Simulation de paiement par carte bancaire avec formulaire sécurisé
-  **Avis Clients** - Système de feedback avec témoignages
-  **Marques** - Présentation des marques disponibles (Audi, Mercedes, Peugeot, Dacia, etc.)
-  **Authentification** - Système de login / register pour les utilisateurs
-  **Responsive Design** - Interface adaptée aux mobiles et tablettes

## 🛠️ Technologies Utilisées

- **Backend** : Python (Flask/Django) + SQLite
- **Frontend** : HTML, CSS, JavaScript
- **Base de données** : SQLite
- **Styling** : Design moderne avec animations et effets visuels
